# Wiska — M5 Rename, Brand, Onboarding & Stats Design

Date: 2026-10-08
Status: Draft for review
Builds on: M1–M4 specs (same date)

## 1. Intent

Turn SecureWispr into **Wiska** — a branded, polished app — and make first run
self-explanatory.

**Stated by user:** name "Wiska"; full rename (option 3) including bundle id,
project, package and GitHub repo; visual direction **Midnight Aurora**; HUD as a
**notch capsule**; onboarding as a **one-page checklist**; stats in the **History
window header + one menu line**.

**Assumed:** GitHub repo is renamed (not deleted) — keeps PR #1, history, tags and
URL redirects; the local working folder `~/Desktop/code/SecureWispr` is not
renamed by Claude (session and memory are keyed to it) — the user may rename it
afterwards.

**Success:** everything user-visible says Wiska with the Aurora look; after the
rename the user's settings, dictionary, history and downloaded Parakeet model are
intact without re-download; a fresh start reaches "ready" via the checklist in
about a minute; stats match History.

## 2. Verified facts (probed 2026-10-08)

- Built-in display: `safeAreaInsets.top = 57`, `auxiliaryTopLeftArea.maxX = 1186.5`,
  `auxiliaryTopRightArea.minX = 1517.5` → notch 331 × 57 pt, centred.
- The 🌐/fn key behaviour setting is **not readable** via `defaults` on macOS 27
  (`AppleFnUsageType` absent, no other domain found) → onboarding row is
  user-confirmed.
- Changing the bundle id resets TCC grants (Microphone, Input Monitoring,
  Accessibility) — unavoidable.

### 3.1 Legacy migration (`LegacyMigration`, Preferences module)

Runs once at launch, before any store is created:
1. **Data folder:** if `Application Support/SecureWispr` exists and
   `Application Support/Wiska` does not → move it (one `moveItem`, so the 469 MB
   model isn't copied). If both exist → leave both, log.
2. **Settings:** for each known key (`engine`, `languageMode`, `primaryLanguage`,
   `toggleLanguage`, `lastDetectedLanguage`, `cleanupLevel`, `historyRetention`),
   if the new defaults have no value and the old domain
   (`UserDefaults(suiteName: "com.zeta.SecureWispr")`) has one → copy it.
3. Sets `migratedFromSecureWispr = true` in the new defaults; never runs again.

Old domain and folder are never deleted by Wiska (beyond the move).

## 4. Brand — Midnight Aurora

`AuroraTheme` (HUD module, public): `ink #0E1116`, `panel #151A22`,
`teal #3EE6C1`, `violet #8B6CFF`, `danger #FF9A9A`, `textPrimary #E8ECF2`,
`textSecondary #8A93A3`; `gradient` = teal → violet (leading → trailing).

- **App icon:** 5 rounded bars (heights 10/26/42/22/8 of a 50-unit box) filled with
  the gradient on a dark radial background (`#1E2633` → `#0B0E13`) inside the
  macOS squircle grid; generated by `scripts/make-icon.swift` (Core Graphics) into
  `Wiska/Assets.xcassets/AppIcon.appiconset` at 16, 32, 64, 128, 256, 512, 1024 px;
  `ASSETCATALOG_COMPILER_APPICON_NAME = AppIcon`.
- **Menu-bar icon:** template image of the same 5 bars (`MenuBarIcon` image set,
  18 pt, template rendering). Warning state keeps `exclamationmark.triangle`,
  listening keeps `mic.fill`.
- Onboarding, History and Settings accents use the theme (gradient title text,
  teal checkmarks, gradient primary buttons). Windows keep system dark/light
  appearance for body text.

## 5. Notch capsule HUD

- **Placement (`NotchLayout`, pure):** input = screen frame, `safeAreaInsets.top`,
  aux left/right areas, desired content size. If `safeTop > 0` and aux areas exist:
  width = max(content width, notch width + 40), height = safeTop + content height,
  top edge = screen top, x centred on the notch. Otherwise: width = content width,
  height = content height, top edge = `visibleFrame.maxY - 6` (just under the menu
  bar), centred on screen. Screen = the one containing the mouse.
- **Window:** borderless non-activating panel at
  `CGWindowLevelForKey(.mainMenuWindow) + 1` (draws over the menu bar),
  click-through, all Spaces, full-screen auxiliary.
- **Shape/colour:** pure black, bottom corners radius 18 (notched) or all corners
  radius 18 (no notch); content laid out in the area below the notch.
- **States:** listening = language badge (teal on 13 % teal) + gradient waveform;
  working = small spinner + "Transcribing…"; message (language flash) = text;
  error = text in `danger`.
- **Animation:** appear by growing height from 0 (0.18 s ease-out); hide reverses.

## 6. Onboarding checklist

Window "Welcome to Wiska" (Window scene id `onboarding`), opened in front:
- automatically at launch when `onboardingCompleted == false` **or** any
  permission is missing;
- from the menu: "Setup…".

Rows (`OnboardingStep`), each with title, one-line reason, status, action:

| Step | Done when | Action |
|---|---|---|
| Microphone | `AVCaptureDevice` authorized | "Allow…" → request (first time) / open Privacy pane |
| Input Monitoring | `CGPreflightListenEventAccess()` | "Allow…" → `CGRequestListenEventAccess` then open pane |
| Accessibility | `AXIsProcessTrusted()` | "Allow…" → prompt then open pane |
| 🌐 key → Do Nothing | user ticked "I've done this" (`fnKeyConfirmed`) | "Open Keyboard Settings" + checkbox |
| Try it | first `onDictationFinished` with `pasted == true` since onboarding opened (`firstDictationDone`) | — |

`OnboardingState` (pure, Preferences module): computes rows' statuses and
`canFinish` (= all three permissions granted; 🌐 and Try-it are recommended,
not required). "Finish" sets `onboardingCompleted = true` and closes.
Permission statuses refresh with the existing 2 s poll; rows update live.
**No permission prompts fire automatically at launch any more** — only from the
rows' buttons.

## 7. Stats

- `DictationRecord.duration: TimeInterval` (seconds of captured audio). The
  controller counts samples it forwards (`samples / 16 000`). SwiftData:
  `HistoryEntry.duration: Double = 0` (lightweight migration; old rows = 0).
- `DictationStats` (pure, History module): from records with `date ≥ now − 7 days`
  and `pasted == true`: `words` = word count of `finalText` (whitespace split),
  `timeSaved = max(0, words / 40 min − Σ duration)`, `swedishShare` /
  `englishShare` = words by language ÷ words with a known language.
- `HistoryStore.stats(now:)` returns it.
- **History header:** three tiles — words this week, time saved, 🇸🇪/🇬🇧 split bar.
- **Menu line:** "This week: 2 340 words · 48 min saved" (grouping per locale;
  minutes rounded; "< 1 min" below a minute). Hidden when retention is Off, history
  unavailable, or no words.

## 8. Error handling

| Situation | Behavior |
|---|---|
| Both old and new data folders exist | Leave both; log; Wiska uses new |
| Folder move fails | Log; Wiska starts with empty data (old folder untouched) |
| No notch / external display | Under-menu-bar capsule |
| User closes onboarding without finishing | Reopens at next launch only if a permission is missing |

## 9. Testing

- **Unit:** LegacyMigration (temp dirs + defaults suites: moves when only old
  exists, keeps both when both exist, copies only missing keys, runs once),
  NotchLayout (notched screen → width ≥ notch + 40, top flush; plain screen →
  below menu bar; centring), OnboardingState (canFinish rules, statuses),
  DictationStats (words, time saved floor at 0, language shares, 7-day window,
  pasted only), controller records duration, HistoryStore round-trips duration
  and `stats`.
- **Build:** app builds as Wiska with icon; `swift test` green in WiskaKit.
- **Manual acceptance (visual):** icon in Finder/Dock/Settings, menu-bar mark,
  notch HUD in all four states on the built-in display and (if available) an
  external display, onboarding from the fresh bundle id (re-grant), data carried
  over (dictionary, history, Parakeet Ready without download), stats match
  History, GitHub repo renamed.
